<h1 align="center">✨ ScreenMeet - Technical Interview Platform ✨</h1>

## Highlights:

- 🚀 Tech stack: Next.js + TypeScript + Convex + Clerk + Stream Video SDK
- 🎥 Real-time video interviews powered by Stream Video
- 📅 Interview scheduling and management system
- 👥 Candidate and interviewer assignment workflow
- 🔒 Secure authentication and role-based access control
- ⚡ Real-time interview updates with Convex
- 🖥️ Screen sharing and meeting recording support
- 🎤 Camera and microphone controls
- 📊 Complete interview lifecycle tracking (Upcoming, Live, Completed, Passed, Failed, Missed, Cancelled)
- 💬 Interview feedback and candidate evaluation workflow
- ⭐ Multi-review rating system with average feedback scoring
- 📝 Create and update interviewer feedback after interviews
- 👀 Candidate feedback portal for reviewing interview outcomes and evaluations
- 🔍 Candidate interview dashboard with status-based filtering and progress tracking
- ⏱️ Expected interview duration management
- 🔄 One-time interview rescheduling support for missed interviews
- ✏️ Interview editing and cancellation functionality
- 🎨 Modern responsive UI built with Tailwind CSS and Shadcn UI
### Run the app

```shell
npm run dev
```
